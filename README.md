# Gutendex Books

A React + Vite application for browsing public-domain books from the [Gutendex API](https://gutendex.com/).

## Live demo

https://julius-astikas.github.io/react-gutendex/

## Features

- Search
- Categories
- Pagination
- Book details
- Favorites saved in localStorage
- Responsive UI
- Loading and error states
- Deployed with GitHub Pages

## Scripts

```bash
npm install
npm run dev
npm run build
```
